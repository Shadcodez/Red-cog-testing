# Chessmaster

Author: SHADOW

Channel chess for Red. One game per channel, one edited message. Text board by default. Image board is optional.

## Install

Add this folder as a Downloader repo path, or copy `chessmaster` into a cog path.

```
[p]addpath <this folder>
[p]load chessmaster
```

Pillow is required for image boards. The bot needs Embed Links, and Attach Files if image mode is on.

## Use

```
[p]chessmaster bot [casual|club|strong] [white|black|random]
[p]chessmaster challenge @member
[p]chessmaster resign
[p]chessmaster mode text
[p]chessmaster mode image
```

The same commands exist as `/chessmaster` after the tree is synced. A live game can switch board style with the Image board button. Resign, mate, draw, or 45 minutes idle wipes the session.
