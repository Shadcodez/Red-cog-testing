# Campaign cog

Original prose on the Wild Hunt road. Not CD Projekt text, not a verbatim port.
Character names are used because this is a fan campaign for a private bot.
Do not claim it is official, and do not sell it.

## Install

Copy the `witcher` folder into your Red cogs path, then:

```
[p]load witcher
[p]witcherset enable
[p]witcher play
```

`[p]help witcher` and `[p]witcher guide` carry the same rules.

## What players can do

- Progress is stored on the Discord user id. Changing channel or server does not reset it.
- `[p]witcher mode dm` moves the whole game to DMs.
- `[p]witcher bind` pins server play to the current channel, after staff enable it.
- `[p]witcher rest` at an inn, dock, or keep mints a resume code.
- `[p]witcher resume WH-XXX-XXX` loads that snapshot.
- Romance fades to black and stays PG-13. It can still move to DMs. `/witcher_scene` is marked age-restricted so Discord hides it from accounts that are not in the adult group.

## Staff

Server play is off until `[p]witcherset enable` is run in that channel.
DMs do not need a channel toggle.

## Scope

Playable main road, major side contracts, Hearts of Stone, Blood and Wine, and romance branches.
It is a full campaign spine with original scenes, not all 450,000 words of the game script.
